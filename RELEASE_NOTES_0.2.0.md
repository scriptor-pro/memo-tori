# Memo Tori v0.2.0 - Release Notes

This release refines the writing experience and continues improving cross-platform packaging.

## Highlights

- UI typography updated: Inter for the interface, IBM Plex Mono for the idea capture field.
- Linux tag releases include an AppImage alongside the .deb.
- Windows installer and macOS DMG are attached to GitHub Releases.

## Changes

### Typography

- Use Inter as the UI font stack.
- Use IBM Plex Mono for the main idea capture textarea.

### Packaging / Release

- GitHub Actions builds and uploads AppImage on tag releases.
- Windows installer workflow uploads the setup executable to the GitHub Release.
- macOS workflow builds and uploads a DMG to the GitHub Release.
